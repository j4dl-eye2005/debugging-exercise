# JavaScript Debugging Exercise

A simple interactive webpage used to practice debugging common JavaScript issues.

## Features

- Enter your name in the input field
- Display a greeting when the button is clicked
- Update the typing message while you type
- Change the page background color
- Reset the page back to its original state

## Files

- index.html — page structure
- style.css — styling for the page
- script.js — interactive behavior and event handlers

## How to Use

1. Open index.html in a browser.
2. Type your name into the input field.
3. Click the buttons to test the page behavior.

## Notes

This project is intended for debugging practice, including issues related to:
- incorrect selectors
- broken event handlers
- runtime errors
- logical issues in the script
